🔎Display Validation
Usage information

Select one or more areas in the reference image that identify the desired display page, such as the unit labels. Every selected area must match before digit recognition is started. The comparison is made after image alignment.

Select Add region, then drag a rectangle around a stable display feature. Choose an area large enough to contain the complete feature, but avoid changing digits. Adjust the similarity threshold if lighting or camera differences cause false rejections.
